The `airprompt` command controls remote mobile access and voice dictation for this Windsurf session. Always run it with the Windsurf provider id: `AIRPROMPT_PROVIDER=windsurf airprompt <command>`. Use `airprompt on` to register, `airprompt off` to unregister, and `airprompt status` to inspect.
